1. 볼록 최적화 문제 (Convex Optimization)
--------------------------------------------------

■ 수학적 최적화

목적 함수(Objective Function)의 값을
최대 또는 최소로 만드는 변수 조합을 찾는 문제

구성 요소
- x : 결정 변수(Decision Variable)
- f(x) : 목적 함수(Objective Function)
- Ω : 가능 집합(Feasible Set)

목표
- 제약조건을 만족하는 해 중
- 목적함수 값을 최적화하는 해 찾기

■ 볼록 최적화

조건
- 목적함수 : 볼록 함수
- 부등식 제약 : 볼록 함수
- 등식 제약 : 아핀 함수

장점
- 지역 최적해(Local Optimum) = 전역 최적해(Global Optimum)

31. 과소적합과 과대적합
--------------------------------------------------

■ Underfitting

특징

Train Loss ↑
Test Loss ↑

원인

- 모델 단순
- Epoch 부족
- Feature 부족

--------------------------------------------------

■ Overfitting

특징

Train Loss ↓
Test Loss ↑

원인

- 모델 복잡
- 데이터 부족
- Feature 과다

--------------------------------------------------

■ Generalization

학습하지 않은 데이터에서도
잘 예측하는 능력

AI 모델의 최종 목표

--------------------------------------------------
★ 시험 직전 암기
--------------------------------------------------

퍼셉트론
= 입력 + 가중치 + 편향 + 활성화함수

순전파
= 예측과 Loss 계산

역전파
= 오차 전달 및 Gradient 계산

Loss
= 학습 기준

Metric
= 평가 기준

CrossEntropy
= 분류

MSE/MAE
= 회귀

CNN
= 이미지

RNN/Transformer
= 시계열·텍스트

Overfitting
= Train↓ Test↑

Underfitting
= Train↑ Test↑

Generalization
= 새로운 데이터에서도 잘 예측
