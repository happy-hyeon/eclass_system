2. Batch
--------------------------------------------------

■ Batch

전체 데이터를 여러 묶음으로 나눈 학습 단위

목적
- 메모리 절약
- 계산 효율 향상

--------------------------------------------------

■ Batch Size

한 번의 학습(Iteration)에 사용하는 샘플 수

예)

데이터 1,000개
Batch Size 100

→ 100개씩 10번 학습

--------------------------------------------------

■ Iteration

배치 하나를 학습하는 과정

예)

1000개 데이터
Batch Size = 100

→ Iteration = 10

--------------------------------------------------

■ Epoch

전체 데이터셋을 1번 학습한 상태

예)

1000개 데이터
Batch Size = 100

10번 Iteration 수행

→ Epoch 1회 완료

3. Gradient Descent 종류
--------------------------------------------------

① Batch Gradient Descent (BGD)

전체 데이터를 한 번에 사용

특징
- 매우 안정적
- Loss Curve 부드러움
- 계산량 큼
- 메모리 사용량 큼

장점
- 안정적 수렴

단점
- 매우 느림
- 대규모 데이터 불가능

--------------------------------------------------

② Stochastic Gradient Descent (SGD)

데이터 1개만 사용

Batch Size = 1

특징
- 매우 빠름
- 메모리 효율적
- Gradient 변동성 큼

장점
- Local Minimum 탈출 유리

단점
- Loss Curve 진동
- 수렴 불안정

--------------------------------------------------

③ Mini-Batch Gradient Descent (MBGD)

현재 가장 많이 사용

특징
- BGD + SGD 절충

장점
- BGD보다 빠름
- SGD보다 안정적
- GPU 병렬처리 가능

단점
- Gradient Variance 존재

--------------------------------------------------
4. BGD vs SGD vs MBGD
--------------------------------------------------

BGD
- 안정성 : 높음
- 속도 : 느림
- 메모리 : 많이 사용
- Local Minimum 탈출 : 불리

SGD
- 안정성 : 낮음
- 속도 : 빠름
- 메모리 : 적게 사용
- Local Minimum 탈출 : 유리

MBGD
- 안정성과 속도의 균형
- 실제 딥러닝 표준

★ 시험 포인트

BGD
→ 안정적

SGD
→ 변동성 큼

MBGD
→ 가장 많이 사용

8. 작은 LR vs 큰 LR
--------------------------------------------------

작은 LR

장점
- 안정적 수렴
- 세밀한 최적화

단점
- 학습 매우 느림
- Local Minimum 탈출 어려움

--------------------------------------------------

큰 LR

장점
- 빠른 학습
- Local Minimum 탈출 유리

단점
- Overshooting 발생
- 발산 가능

--------------------------------------------------

★ 시험 포인트

너무 작은 LR
→ Slow Convergence

너무 큰 LR
→ Overshooting
